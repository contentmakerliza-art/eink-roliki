# eink-roliki

## Артикулы в описаниях (для Wibes)
Каждому новому ролику — случайная модель из `queue/wibes_articles.json`, в описании `WB, арт. A арт. B арт. C` (все цвета этой модели, через пробел, без запятых). Карточки на WB склеены. Хуппи (автоматизация YouTube→Wibes) вырезает описание и хештеги, оставляет заголовок + art:A art:B art:C, Wibes прикрепляет все товары.
